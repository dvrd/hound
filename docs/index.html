Get hound

Up in three
commands.

Requires Go 1.21+ and Task. Works on macOS and Linux.

1
Clone the repository
Grab the source from GitHub
2
Build the binary
Compiles to ./bin/hound
3
Install system-wide
Run hound from anywhere
bash
$ git clone https://github.com/dvrd/hound.git
$ cd hound
$ task build # → ./bin/hound
$ task install # install system-wide
$ hound # launch 🐕
