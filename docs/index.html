Capabilities

Everything you need.
Nothing you don't.

Built for developers and power users who live in the terminal. No Electron. No browser. No bullshit.

01 / Portfolio

Full portfolio at a glance

SOL and every SPL token with live USD values and 24h change. Preloaded in the background — the first view is never blank.

preloaded on startup
02 / Swaps

Jupiter-powered swaps

Best routes, lowest slippage — executed directly from the TUI through Jupiter's aggregator. No browser tab required.

via Jupiter API
03 / Intel

Token deep-dive

Market cap, top holders, price history — all surfaced inline. Research without leaving your shell.

real-time data
04 / Compat

Phantom-compatible

BIP44 derivation matches Phantom, Solflare, and Ledger exactly. Same seed phrase — same wallets.

BIP44 standard
05 / Security

AES-256 encrypted

AES-256-GCM + Argon2id. Sensitive data zeroed from memory. Your keys never leave your machine.

zero telemetry
Get started

Up in three
commands.

Requires Go 1.25+ and Task. macOS & Linux.

01
Clone the repository
git clone github.com/dvrd/hound
02
Build the binary
compiles to ./bin/hound
03
Install system-wide
run hound from anywhere
bash
$ git clone https://github.com/dvrd/hound.git
$ cd hound
$ task build
→ ./bin/hound compiled
$ task install
→ installed to /usr/local/bin
$ hound   # 🐕 launch
